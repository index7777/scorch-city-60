# Scorched City 60 — External Asset Shortlist

Status: shortlist only. No third-party file in this list is shipped in the game yet.

Selection rules for this project:
- Commercial use must be allowed.
- Prefer CC0 or similarly permissive terms.
- No emoji-based UI assets.
- No electronic beeps, arcade UI tones, chiptune, or sci-fi terminal sounds.
- Music should favor slow drone, environmental ambience, low mechanical texture, wind, ventilation, concrete/industrial space.
- Every adopted file must record title, author, source page, license, download date, local filename, and edits.

## Visual / structural assets

### Kenney — UI Pack
Source: https://kenney.nl/assets/ui-pack
License: Creative Commons CC0
Use: candidate for neutral buttons, sliders, panels, and settings controls. Do not use the pack as the main art direction without restyling.

### Kenney — City Kit (Industrial)
Source: https://www.kenney.nl/assets/city-kit-industrial
License: Creative Commons CC0
Use: candidate reference / raw geometry for industrial buildings, warehouses, vents, and utility structures. If used in the final 2D game, render or repaint into the established Scorched City visual language rather than dropping stock 3D renders directly into the map.

### Kenney — Factory Kit
Source: https://kenney.nl/assets/factory-kit
License: Creative Commons CC0
Use: candidate source for pipes, industrial machinery, warehouse props, ducts, tanks, and factory silhouettes.

## Rejected directions

- Kenney Interface Sounds / UI Audio: license is suitable (CC0), but the packs are not shortlisted for direct use because this project explicitly avoids electronic / game-like button feedback. A physical click may be sourced later from real mechanical Foley instead.
- Sci-fi UI packs: do not use as primary interface styling.
- Beat-driven industrial music: reject.
- Chiptune, synthwave, cyberpunk UI tones, terminal beeps: reject.
